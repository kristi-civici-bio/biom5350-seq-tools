# biom5350-seq-tools
This repository consists of a Python script for analyzing DNA sequence data in FASTA files for Intro to BioInfo (BIOM5350)

## Usage

You can run the script using the following command:

	python gc_content.py example.fasta

## Output

The script's output will reveal the length, GC%, and AT% of each DNA sequence and calulate/show the mean GC% across all DNA sequences
